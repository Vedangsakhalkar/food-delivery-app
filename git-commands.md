# Scaffolding a new project


1. Create a new folder called food-delivery-app
2. Execute the commands given below in the folder that you just created
3. Create a new repository on github.com (public / private)
4. Copy paste the commands from github on your commands prompt in the same folder : food-delivery-app
5. Make sure that your files (.gitignore ) file is there on the server
6. Open the folder in VS Code 
7. Create a new file called README.md and put something in it (# My Learning App)
8. Use VS Code -> VCS -> Push the README.md file to the server
9. Make sure that ypu can see the file on the server


- git init
- touch .gitignore | On windows : echo "This is a test file" >> README.md
- git add --all
- git commit -m "initial"
